# AkaDako Multi Cloud Logger(β)

AkaDako ボードや S-LiNKデバイスのセンサーの値をブラウザでリアルタイムに表示・記録する、1ファイル構成の教材用Webアプリです。

## 機能

- Web MIDI 経由で AkaDako ボードや S-LiNKデバイスに自動で接続（USB でつなぐだけ。「接続」の操作はない）
- センサー14項目: 温度・照度・距離・湿度・気圧・重力・傾き・動き・音量・水温・酸素・電流・電圧・電力（タブは、左はしの AI と右はしの「外部」を合わせて 16 個。1366px 幅の画面で 1 段におさまる）
  - 「動き」はパソコンのカメラ、「音量」はマイクを使うため、S-LiNKデバイスなしでも測れます
- 記録していないときも現在値を1秒ごとに更新
- 記録間隔は 0.5秒/1秒/2秒/5秒/10秒/30秒/1分/10分（初期値は 0.5秒）。10秒より長い間隔は、何時間もかけてゆっくり変わるものを測るとき用。「音量」だけは 0.1秒 も選べる（マイクの値を読むだけで速いため。S-LiNKデバイスのセンサーは MIDI の往復があるので 0.5秒まで）
  - 1秒より短い間隔で記録した項目は、表と CSV の時刻に 1/10 秒が付く（例 `10:23:45.3`）
  - ブラウザのタブが裏に回ると、タイマーが 1秒に丸められて 0.1秒・0.5秒でも 1秒ごとにしか記録されない（ブラウザの仕様）。裏に回ったまま 5 分以上たつと、Chrome はタイマーをさらに間引く（1 分に 1 回ほど）ことがあるので、10秒・30秒の間隔で長く測るときは、このページを前に出したままにする。パソコンがスリープすると記録は止まる
  - 次に記録する時刻は「前の予定 + 間隔」で決める（`nextSaveAt`）。読めた時刻から数えると、長い間隔で 1 件ごとに少しずつ遅れていくため。記録していない間も現在値は 1秒ごとに測り直し、予定の時刻ちょうどに記録する
- グラフ表示と表表示の切り替え
  - グラフにマウスを乗せると、いちばん近い記録の時刻と値が出る（くらべているときは上下のパネルそれぞれに）。タッチでは指を置いている間だけ
  - 縦軸の目盛りは値の範囲に合わせて決める。値が全部 0 以上のときは、軸を 0 より下に広げない（太陽の高さ・照度・降水量などで、マイナスの目盛りを出さない。測定室のページも同じ）
  - グラフの下のスクロールバー（横幅はグラフの描画域＝X 軸と同じ）: 灰色の部分の中央を左右にドラッグすると見える時間帯が動き、両端の濃いつまみをドラッグすると見える範囲の長さが変わる（2 件〜全部。初期値は直近 120 件）。右端まで動かすと最新の記録を追いかける
  - 記録が止まっているときにグラフの上を左右にドラッグすると、その範囲が灰色になり、「この範囲を拡大」で選んだ範囲をグラフいっぱいに出せる（記録は消えない）。「この範囲以外のデータを消去」は確認のあと、範囲の外の記録を消す（番号はそのまま。くらべているときは相手のセンサーも同じ時間帯だけ残る）
- 「くらべる」スイッチで 2〜3 つのセンサーを同時に測り、グラフを上下に並べる・1 枚に重ねる（下の「くらべる」を参照）
- 記録ごとのメモ: 表のいちばん右の「メモ」列（空の行は何も出ず、行に乗せると「クリックして書く」が出る）に書くか、グラフの記録をクリック（タップ）して出る枠に書く（記録中でも書ける。枠は右上の ✕ で閉じる。写真も付けられる → 下の「カメラと写真」）。メモのある記録にはグラフに黄色い吹き出しの印が付き（山なら点の上、谷なら点の下）、マウスを乗せると値と一緒にメモが出る。CSV・TSV のいちばん右にも「メモ」列が付く。測定室に参加している間は、メモ（文と写真）も測定室に送る
- CSV ダウンロード / TSV コピー（Excel・スプレッドシートに貼り付け）
- 「測定室」: 複数の端末の測定データを集めて 1 つのページで見る（下の「測定室」を参照）
- `?mode=demo` を付けて開くと、S-LiNKデバイスの代わりに乱数の値を流すデモになる（見た目の確認用。マイク・生成AI は使わない。記録はブラウザに保存しない）。つながっていないときにセンサーのタブを押すと「S-LiNKデバイスが接続されていません。デモモード（にせものの数字）に切り替えますか？」と聞かれ、「はい」でも入れる（S-LiNK がいらない「動き」「音量」のタブでは聞かない。聞くのはページを開いてから 1 回だけで、接続をためしている間は聞かない。「いいえ」ならそのままタブが切り替わる）。画面の上の「AkaDako 未接続」を押してさがしても MIDI ポートが 1 つも見つからなかったときも同じダイアログが出る（ポートはあるのに認識できないときや Web MIDI を許可しなかったときは、直せる問題なので勧めない）。デモ中は上の「デモ値（乱数）」の横の「終了」で通常の画面に戻る。出入りはページを開き直すので記録は消える
- 「AI」タブで AI 計測: 記録間隔（5秒/10秒/30秒/1分/10分）ごとにカメラの画像とプロンプトを AkaDako 生成AI に送り、答えの数字を表・CSV に記録（回答文も一緒に残ります）
  - 利用には S-LiNKデバイスの接続と、[AkaDako Cloud Plus のアクセスコード](https://699.jp/cp) の登録が必要です
  - アクセスコードの Cookie は xcratch.699.jp のものなので、同一サイトになる https://log.699.jp/ から開いてください

## 外部のデータ（「外部」タブ）

タブのいちばん右の「外部」は、自分で測っていないデータを 1 つえらんで、グラフや表にならべるためのもの。押すと、えらぶ画面が出る（「外部」だけを出しているときにもう一度押すと、えらび直し）。

| えらべるもの | 中身 |
|---|---|
| 太陽の高さ | 場所（都道府県。県庁のある市の緯度・経度）と時刻から計算する（`sunElevation`。地平線が 0°。しずんでいる間は 0° にする）。通信はしない |
| アメダス | 気象庁が全国ではかっている、降水量・風速・風向・日照時間（10 分ごと）。下の「アメダス（気象庁）」 |
| 前の記録 | このアプリの「ダウンロード」で保存した CSV か ZIP を読みこむ。くらべたときの CSV のように項目がいくつもあるときは、項目を 1 つえらぶ。そろえ方は「はじまりをそろえる」（記録をはじめてからの時間で合わせる。初期値）か「時刻をそろえる」（日付だけずらして、同じ時刻どうしを合わせる） |

- **値は時刻から決まるので、記録としては持たない**。`dataStore.external` は、条件が変わるたびに `syncExternal` が作り直す（IndexedDB にも保存しない。保存するのは、えらんだ内容 `ui.external` と、読みこんだファイル `meta` の `extFile`）
- **センサーとくらべているとき**（くらべる ON で、センサーと「外部」をえらぶ）: 主センサーの記録の時刻ごとに値を出す。あとから「外部」を足しても、それまでの記録の分まで線が出る。並べる・重ねる・表の列・CSV は、ほかのセンサーと同じ。前の記録が同じ名前のセンサー（例: 温度）なら単位を合わせるので、重ねたとき軸が共通になる。前の記録の範囲の外の時刻は、空になる
- **外部は主センサーにしない**（表・CSV・測定室の行の基準は、自分で測ったセンサーの記録）。くらべる ON で「外部」を押すと、いまの主センサーはそのままで、相手として足される
- **「外部」だけのとき**は見るだけ（「記録をはじめる」を押すと、その案内が出る）。太陽の高さは今日 1 日ぶん（0 時から 24 時まで 10 分ごと）、前の記録はファイルの中身をそのまま出す
- 電力などを足すときは、同じ `ext` の種類として足し、通信は `logdb.699.jp` を経由させる（*.699.jp だけで動かすため）

### アメダス（気象庁）

- えらぶもの: 都道府県 → 地点 → 項目（降水量・風速・風向・日照時間。その地点ではかっている項目だけが出る）。都道府県をえらぶと、はじめに県庁のある市の地点が出る
- 値は `logdb.699.jp` が気象庁から取ってきたものを受け取る（`GET /amedas/stations` で地点の一覧、`GET /amedas/地点番号?from=&to=` で 10 分ごとの値。ブラウザは気象庁に直接つながない）。気象庁のページが使っている JSON で、公式の API ではないので、形が変わると取れなくなることがある。さかのぼれるのは約 10 日
- 項目: 降水量（その 10 分間に降った量。mm）、風速（m/s）、風向（北が 0°、東が 90°、南が 180°、西が 270°。風が無いときは値なし）、日照時間（その 10 分間のうち日が照っていた時間。分）
- 当てはめ方（`amedasValue`）: 降水量・日照時間・風向は、その時刻をふくむ 10 分間の値。風速は前後の値のあいだをまっすぐ結ぶ
- 新しい値は観測から 10〜20 分おくれて出るので、記録したばかりのところは空になる。「外部」をえらんでいる間は 5 分ごとに取り直し（`loadAmedas`）、届いたら空だったところが埋まる
- 名前は「アメダス風速（古河）」の形にする（「古河の風速・湿度」と並ぶと、湿度まで古河のものに見えるため）。見出しなどの名前は、自分で測ったセンサーを先に、外部のデータをあとに並べる（`activeName`。例: 湿度・アメダス風速（古河）の変化）
- 「外部」だけのときは、その地点の今日 0 時からの値が出る。グラフの見出しに「出典：気象庁（アメダス）」と出す

## カメラと写真

左のカードに、カメラの映像をいつも出す（ページを開いたときにカメラを始めるので、はじめて開いたときにカメラの許可を聞かれる。使えないときは枠に理由と「もう一度ためす」が出る）。「動き」と AI も同じ映像を使う。

- **メモに写真を付ける**: グラフの記録を押して出るメモの枠は、写真が上・メモの文が下の並び。「写真をとる」でとると見本が出て（見本の右に「とり直す」「写真を消す」）、見本の右下の虫めがねで大きく見られる。「保存」でメモの文と一緒にその記録に付く（「とり直す」「写真を消す」もできる。「消す」はメモも写真も消す）
- **写真の記録（自動）**: 映像の下の「写真の記録」で OFF（初期値）／10秒・30秒・1分・5分・30分・1時間ごと／自動（大きな変化）を選ぶ。記録しているあいだだけ撮り、写真はその周期の主センサーの記録にメモとして付く
  - 写真は記録と同じ時刻にしか撮らない（記録と記録の間では撮らない）。そのため、記録間隔より短い周期は選択肢に出さない（`syncPhotoModes`）。記録間隔と同じ周期には「（記録のたび）」と付く。例: 記録が 10 分間隔なら「10分ごと（記録のたび）／30分ごと／1時間ごと／自動」。記録間隔を長くして、選んでいた周期が短すぎになったら「記録のたび」に直す
  - 周期: 記録をはじめた 1 件目に 1 枚、そのあとは前の写真からその時間がたった最初の記録で 1 枚
  - 自動: 記録をはじめた 1 件目に 1 枚。そのあとは、選んでいるセンサーのどれかが「前の写真のときの値」から決めた幅（`PHOTO_STEP`。温度 2℃・湿度 5%・照度 200lx・距離 10cm など）以上変わったら 1 枚。前の写真から 10 秒（`AUTO_PHOTO_GAP`）はあける
  - 写真が 2,000 枚（`PHOTO_MAX`）になったら、写真の記録を OFF にする
  - 「写真の記録」を OFF から ON にすると、「必ず顔や個人情報が撮影されないように設置してから記録をはじめてください」というダイアログが出る（「OK」で ON のまま、「やめる」か Esc で OFF にもどる。周期を変えるだけのときと、開き直して前の設定に戻ったときは出ない）
- **グラフ**: 写真のある記録は、線の上に小さな丸が付く（ふきだしは文字で書いたメモだけ。自動で撮るとふきだしだらけになるため）。マウスを乗せると、値とメモの下に写真の見本が出る
- **表**: 写真のある行は、メモ欄の右にカメラの印が出る。マウスを乗せると写真が浮かび、押すと大きく見られる
- 写真は 640px 幅の JPEG（1 枚 50〜80KB ほど）。画像は IndexedDB の `photos` に入れ、記録には写真の番号（`item.photo`）と小さな見本（`item.thumb`）だけを持たせる
- **ダウンロード**: 写真のある記録をダウンロードすると、CSV と写真をまとめた ZIP（`AkaDako_センサー名_日時.zip`）になる。中身は `AkaDako_日時.csv`（いちばん右に「写真」の列＝ファイル名）と `photos/日時_番号.jpg`。ZIP の中の名前は半角の英数字だけ（日本語の名前は、解凍ソフトによっては文字化けして取り出せないため）。圧縮はしない（JPEG はすでに圧縮されている）。写真が無ければ今までどおり CSV だけ。コピー（TSV）には写真は入らない
- 測定室に参加している間は、写真もメモの文と一緒に測定室に送る（下の「測定室（共有）」）。写真の記録を ON にするときの注意（顔や個人情報が写らないように）は、このためでもある

## 記録の保存（開き直しても続きから）

記録・メモ・写真と画面のようす（選んでいるセンサー・くらべる・並べる／重ねる・グラフ／表・記録間隔・写真の記録・AI のプロンプト）を、ブラウザの IndexedDB（データベース名 `akadako-multi`）に残す。ページを閉じたり端末を再起動したりしても、次に開くと前の画面に戻る（「前の記録のつづきから表示しています」と出る。記録は止まった状態で始まり、「記録をはじめる」を押すと続きの番号から記録する）。

- 保存先: `records`（記録 1 件ごと。キーは [センサー, 番号]）、`photos`（写真の画像）、`meta` の `ui`（画面のようす）。書きこみは 0.4 秒ためてまとめて行い、ページを閉じる・裏に回るときはすぐ書く
- 消すには「削除」ボタン（選んでいるセンサーの記録と写真が、保存先からも消える）
- 同じページを 2 つのタブで開くと記録がまざるので、保存するのは先に開いたタブだけ（Web Locks）。あとから開いたタブには「ほかのタブでも開いているので、このタブの記録は保存されません」と出る
- デモモードと `?store=off` では保存も復元もしない
- 共用のパソコン（同じアカウントを何人もが使う端末）では、前の人の記録と写真が次の人に見える。その場合は使い終わりに「削除」を押す

## 使い方

1. https://log.699.jp/ を開く（手元で動かすときは `index.html` を `https://` か `localhost` 経由で開く）
2. S-LiNKデバイスを USB でつなぐ。自動で接続され、画面の上の「AkaDako」の表示が緑の「接続中」になる（印が橙で点滅している間は、つなごうとしているところ。ケーブルを抜くと「未接続」に戻り、挿し直すとまたつながる）
   - 初回だけ、ページを開いたときにブラウザが MIDI デバイスの使用許可を聞く
   - ページを開く前から挿してあっても、開いたあとで挿してもよい。ポートの増減は `statechange` と 3 秒ごとの確認で見張り、新しいポートが現れたら最大 3 回ためす
   - ケーブルは挿さったまま通信だけ切れたとき（スリープ明けなど）や、3 回ためしてもつながらなかったときは、ポートがあるかぎり約 10 秒ごとに静かにためし直す
   - 自動でつながらなかったときは「AkaDako 未接続」を押すと、もう一度さがす。つながっているあいだは押しても何も起きない（切るときはケーブルを抜く）
3. センサーのタブを選び、「記録をはじめる」で記録を開始

外付けの機器が必要なセンサー（水温・酸素・電流・電圧・電力）は、タブを押したときに接続先の案内が出ます。

## くらべる（3つまでのセンサー）

画面の上、接続状態の左にある「くらべる」スイッチ（初期値 OFF）を ON にすると、センサーのタブを押したときの動きが「切り替え」から「追加」に変わる。

- ON で別のタブを押すと、それまでのセンサーに加わって 2 つ、3 つと並ぶ（押したセンサーが主になる）。同時に測れるのは 3 つまで（`COMPARE_MAX`）で、4 つ目を押すと、いちばん古いものが外れる
- チェック印の付いたタブをもう一度押すと、そのセンサーが外れる（グラフが 1 つ減る）。主センサーを外したときは、その前に押したセンサーが主になる。最後の 1 つは外れない。外したセンサーの記録は消えず、選び直せば続きから測る。外したとき・4 つ目で入れ替わったときは、画面の下のお知らせで何が外れたかを出す。足した直後（0.7 秒以内）に同じタブをもう一度押したとき（ダブルクリック）は外さない
- 記録中にセンサーを外して、読めるセンサーが 1 つも残らなくなったときは、記録をとめる（センサーの切り替えでも同じ）
- OFF にすると、主センサーだけが残る。AI タブを押すと OFF に戻る。OFF のときは、選んでいるタブを押しても何も起きない
- 2 つ以上選んでいる間は、左のカードに「色・名前・現在値・最小/平均/最大」の行がセンサーごとに並び、タブにはチェック印が付く
- 選んだセンサーを同じ周期で順に読み、同じ時刻でそれぞれの記録に残す（記録の保存先は単独のときと同じ。いちばん新しく選んだセンサーが「主」で、表・グラフの表示範囲・測定室の行はその記録を基準にする）
- グラフは時間軸を共通にして、古いほうを上・主センサーを下に並べる。相手の記録は時刻で主センサーに合わせる（選ぶ前に記録した分も、同じ時間帯なら出る）。グラフの箱が高くなる（2 つで 380px 以上、3 つで 540px 以上）ので、低い画面ではページがスクロールする。左のカードの下の部品（グラフ／表・記録ボタン・記録間隔）は、幅 841px 以上の画面では画面の下に残る（`position: sticky`）ので、スクロールしなくても記録をはじめられる・とめられる
- グラフの見出しの右に出る「並べる｜重ねる」で、1 枚に重ねることもできる（ページを開いたときはいつも「並べる」から）。縦軸は単位ごとに 1 本で、選んだ順に 左・右・いちばん右（右の軸の外側）に置く。センサーが 1 つだけの軸はそのセンサーの色、同じ単位のセンサー（温度と水温など）で共有する軸は灰色で描き、目盛りの本数をそろえて横線を共有する。全部が同じ単位なら 1 本の共通の軸
- 重ねたときの線は、選んだ順に 実線・破線・点線（`OVERLAY_DASHES`）にし、グラフの中のセンサー名の前に線の見本を付ける。色の似た組（湿度と電流、気圧・電力・水温など）でも見分けられるようにするため。並べる表示はどれも実線のまま
- 軸が 3 本になる組（3 つとも単位が違う）は右の余白が 2 本ぶん要るので、線を描く幅が 240px（`OVERLAY_MIN_PLOT`）に足りない画面（グラフの幅でおよそ 395px 未満）では「並べる｜重ねる」を出さず、並べる表示だけにする
- 表と CSV は時刻ごとに 1 行、センサーごとに 1 列（CSV の見出しに単位）。削除は選んでいるセンサーをまとめて消す
- 測定室には選んでいるセンサーを 1 本のストリームで送る（測定室のタイルにセンサーの数だけ線と現在値が出る。サーバー側の上限は 1 端末 6 センサー）。組を変えると新しいセッションになる
- 記録間隔は 0.5秒 から。音量の 0.1秒 は音量を単独で測るときだけ

## 測定室（共有）

s-link-logger（Logger Builder）の測定室を移植したもの。仕組みは同じだが、環境は s-link-logger から独立している（Logger Builder の端末とは別の測定室になる）。

- API: `https://logdb.699.jp`（AWS。Lambda のコードと構成は、非公開の別リポジトリ multi-logger-cloud。手元では `../akadako-multi-cloud`）
- 測定室のページ: このリポジトリの `room.html`（`https://log.699.jp/room.html?room=内部ID`。短い URL は `https://logdb.699.jp/r/内部ID`）。もとは s-link-logger の `src/room.html` の複製。そのあと、既定の API・`?api=` の制限・メモと写真の表示を、こちらだけに足している（s-link-logger 側とは別のものとして直していく）


- 画面右下の「測定室」ボタンで作成・参加する。ボタンの丸い印で、データを送れているか（緑）・送れていないか（橙）が分かり、公開中はボタンに「（公開中）」と出る
- 「作成する」… 測定室の名前と自分の端末名を入れると 6 桁の測定室 ID ができる。「自身のデータ共有」を外すと、作成した端末は測定室を管理するだけで自分のデータは送らない
- 「参加する」… 測定室 ID と自分の端末名を入れる。6 桁そろうと測定室の名前が出るので、確かめて「参加する」
- 「別タブで測定室を表示」… 端末ごとのタイル（現在値と小さなグラフ）。タイルを押すと 1 台を大きく見る（並べる／重ねる・表）、チェックした端末を重ねて表示、ダウンロードができる
- 測定室のページの見た目とグラフの描き方は、この画面にそろえてある（左に現在値、右にグラフ・表。線・塗り・目盛り・破線と点線も同じ）。違いは、帯・背景・ボタンがオレンジ系なこと（この画面は青）と、帯の左の「測定室」の札。グラフの描き方をこの画面で変えたときは、`room.html` の描画（`drawPanel`・`drawOverlaid`・`drawHover`）も同じに直す
- 作成者は「公開する」で、URL を知っている人にも見せられる（URL のコピーと QR コード）。「終了する」は 2 回押しで確定
- 送るのは「いま選んでいるセンサーの記録」（くらべているときはその組）。5 秒ごとに差分を送り、センサーを切り替えたり記録を削除したりすると、新しいセッションとしてその端末の分をサーバー側で入れ替える（AI タブも同じ。回答文は送らない）
- 送信には回数の上限がある（端末ごとに 1 分 60 回。ふつうは 5 秒に 1 回なので届かない）。通信が切れていた間の記録をまとめて送っていて上限に届いたときは、何も出さずに次の周期で続きを送る
- **メモ（文と写真）も送る**（`syncMemos`）。行（主センサーの記録の番号）ごとに、表と同じメモの文と写真を、送ってある内容とくらべて、ちがうところだけ送る（消したメモは消す）。写真は 1 回（5 秒）に 3 枚まで、先に写真を送ってからメモを送る。ページを開き直したときは、サーバーに残っている内容を読んでからくらべるので、写真は送り直さない。測定室の画面（ダイアログ）に「記録のほか、メモと写真も測定室に送られます」と出す
  - 測定室のページでは、1 台を大きく見る画面で見られる。グラフは手元の画面と同じ印（写真は線の上の小さな丸、文はふきだし。乗せると文と写真の見本。メモのある記録を押すと、手元の画面と同じ形のメモの枠が出る。見るだけで、書きかえ・とり直し・削除はできない）、表はいちばん右の「メモ」列（写真のある行にカメラの印。乗せると浮かび、押すと大きく見られる）。一覧のタイルには「メモ ○」と出る
  - 見られるのは、記録と同じ人（作成者・参加中の端末。公開中は URL を知っている人も）。測定室のダウンロード（CSV・Excel）には、メモと写真は入らない
- 端末の登録と測定室はブラウザ（localStorage）に残り、ページを開き直しても続く。最後の送信から 1 週間で自動で消える。登録は API ごとに覚える（`st.api`）ので、前の API（`logdb.s-link.education`）での登録は引き継がない。API 側で登録が消えていたときは、作成・参加のときに登録し直す（`withStream`）
- QR コードの生成は `qrcode.js`（qrcode-generator v1.4.4、MIT）を、押されたときだけ読み込む

## 説明書（使い方）

画面の上の「使い方」ボタンで、小学生向けの説明書 `manual.pdf` が別タブで開く。

- 元は `manual/index.html`（ふりがなは `{漢字|かんじ}` と書く）。画面写真は `manual/img/`
- 作り直すとき: `manual/tools/build.sh`（`shots` で画面写真の撮り直し、`pdf` で PDF の作成。引数なしで両方）。Chrome のヘッドレスモードを使う
- 画面写真は、`s-link.js` をにせもののS-LiNKデバイス（`manual/tools/mock.js`）に差し替えた複製を、台本（`manual/tools/scenes.js`）どおりに動かして撮る。アプリの画面を変えたら撮り直して、説明や番号の位置を見直す
- `mock.js` はにせもののカメラも兼ねる（ヘッドレスの Chrome にはカメラが無いので、絵を描いた canvas の映像を `getUserMedia` で返す。絵は「つくえの上のセンサー」で、値が上がっているあいだは手がうつる）。時計を早回ししたままで、映像も「写真をとる」も動く
- 場面どうしで記録がまざらないように、撮るときの URL には `?store=off` を付ける。「開き直しても続きから」の写真（`shot-restore.png`）だけは保存を使うので、専用のプロフィールで 2 回開いて撮る（1 回目に記録し、2 回目は実時間で待って撮る）
- 写真まわりの場面: `memophoto`（メモの枠で写真をとったところ）・`photohover`（10秒ごとに撮ったグラフの黒い丸に乗せたところ）・`phototable`（表のカメラの印に乗せたところ）
- 「外部」タブの場面: `extpick`（えらぶ画面）・`extsun`（太陽の高さだけ）・`extprev`（温度と「前の記録」を重ねたところ。前の記録は、台本が作った CSV を、ファイルをえらぶ入力 `#extFileInput` に入れて読ませる）
- 「共有しよう」の章の「重ねて表示」の写真（`shot-share-*.png`）だけは、測定室のページ（`room.html`。場所は `ROOM_HTML` で変えられる）を、にせものの測定室（`manual/tools/room-mock.js`。3 つの班の記録を返す）で開いて撮る。`build.sh room` でこの 2 枚だけ撮り直せる

## URL パラメータ

| パラメータ | 内容 |
|---|---|
| `mode=demo` | S-LiNKデバイスの代わりに乱数の値を流す（接続ボタンの代わりに「デモ値（乱数）」と「終了」が出る） |
| `api=URL` | 測定室の共有 API の URL（既定 `https://logdb.699.jp`。開発用） |
| `store=off` | 記録をブラウザに保存しない・前の記録を戻さない（説明書の写真を撮るとき用） |
| `preview=ipad` | PC で iPad 向けの「Scrub で開く」案内を確かめる |

## 動作環境

- Web MIDI API に対応したブラウザ（Chrome、Edge など）
- iPad は Safari / Chrome に Web MIDI が無いため、Scratch専用ブラウザ [Scrub](https://apps.apple.com/jp/app/scrub/id1569777095) で開いてください。iPad の通常ブラウザで開くと「Scrub で開く」の案内が出ます（`scrub://openUrl?<このページのURL>` で Scrub に渡します）。PC で案内の表示を確かめるには `?preview=ipad` を付けます
- AkaDako ボード / S-LiNKデバイス
- カメラ・マイクを使う項目は `https://` または `localhost` での配信が必要です（`file://` では許可されない場合があります）
