# S-LINK Multi Logger(β)

AkaDako / S-LINK センサーボードの値をブラウザでリアルタイムに表示・記録する、1ファイル構成の教材用Webアプリです。

## 機能

- Web MIDI 経由で AkaDako / S-LINK ボードに接続
- センサー14項目: 温度・照度・距離・湿度・気圧・重力・傾き・動き・音量・水温・酸素・電流・電圧・電力
  - 「動き」はパソコンのカメラ、「音量」はマイクを使うため、ボードなしでも測れます
- 記録していないときも現在値を1秒ごとに更新
- 記録間隔は 0.5秒/1秒/2秒/5秒。「音量」だけは 0.1秒 も選べる（マイクの値を読むだけで速いため。ボードのセンサーは MIDI の往復があるので 0.5秒まで）
  - 1秒より短い間隔で記録した項目は、表と CSV の時刻に 1/10 秒が付く（例 `10:23:45.3`）
  - ブラウザのタブが裏に回ると、タイマーが 1秒に丸められて 0.1秒・0.5秒でも 1秒ごとにしか記録されない（ブラウザの仕様）
- グラフ表示と表表示の切り替え
  - グラフにマウスを乗せると、いちばん近い記録の時刻と値が出る（くらべているときは上下のパネルそれぞれに）。タッチでは指を置いている間だけ
  - グラフの下のスクロールバー（横幅はグラフの描画域＝X 軸と同じ）: 灰色の部分の中央を左右にドラッグすると見える時間帯が動き、両端の濃いつまみをドラッグすると見える範囲の長さが変わる（2 件〜全部。初期値は直近 120 件）。右端まで動かすと最新の記録を追いかける
  - 記録が止まっているときにグラフの上を左右にドラッグすると、その範囲が灰色になり、「この範囲を拡大」で選んだ範囲をグラフいっぱいに出せる（記録は消えない）。「この範囲以外のデータを消去」は確認のあと、範囲の外の記録を消す（番号はそのまま。くらべているときは相手のセンサーも同じ時間帯だけ残る）
- 「くらべる」スイッチで 2 つのセンサーを同時に測り、グラフを上下に並べる（下の「くらべる」を参照）
- 記録ごとのメモ: 表のいちばん右の「メモ」列（空の行は何も出ず、行に乗せると「クリックして書く」が出る）に書くか、グラフの記録をクリック（タップ）して出る枠に書く（記録中でも書ける）。メモのある記録にはグラフに黄色い吹き出しの印が付き（山なら点の上、谷なら点の下）、マウスを乗せると値と一緒にメモが出る。CSV・TSV のいちばん右にも「メモ」列が付く。メモは測定室には送らない
- CSV ダウンロード / TSV コピー（Excel・スプレッドシートに貼り付け）
- 「測定室」: 複数の端末の測定データを集めて 1 つのページで見る（下の「測定室」を参照）
- `?mode=demo` を付けて開くと、ボードの代わりに乱数の値を流すデモになる（見た目の確認用。カメラ・マイク・生成AI も使わない）。「ボード接続」を押して MIDI ポートが 1 つも見つからなかったときは「ボードが見つかりませんでした」のダイアログが出て、「デモモードにする」でも入れる（ポートはあるのに認識できないときや Web MIDI を許可しなかったときは、直せる問題なので勧めない）。デモ中は上の「デモ値（乱数）」の横の「終了」で通常の画面に戻る。出入りはページを開き直すので記録は消える
- 「AI」タブで AI 計測: 記録間隔（5秒/10秒/1分/10分）ごとにカメラの画像とプロンプトを AkaDako 生成AI に送り、答えの数字を表・CSV に記録（回答文も一緒に残ります）
  - 利用には S-LINK ボードの接続と、[AkaDako Cloud Plus のアクセスコード](https://699.jp/cp) の登録が必要です
  - アクセスコードの Cookie は xcratch.699.jp のものなので、同一サイトになる https://log.699.jp/ から開いてください

## 使い方

1. https://log.699.jp/ を開く（手元で動かすときは `index.html` を `https://` か `localhost` 経由で開く）
2. 画面の上の「ボード接続」スイッチを ON にして S-LINK ボードに接続（印が橙で点滅している間は接続中。つながると緑で ON、失敗したりケーブルが抜けたりすると OFF に戻る）
3. センサーのタブを選び、「記録をはじめる」で記録を開始

外付けの機器が必要なセンサー（水温・酸素・電流・電圧・電力）は、タブを押したときに接続先の案内が出ます。

## くらべる（2つのセンサー）

画面の上、接続状態の左にある「くらべる」スイッチ（初期値 OFF）を ON にすると、センサーのタブを押したときの動きが「切り替え」から「2つ目にする」に変わる。

- ON で別のタブを押すと、それまでのセンサーと 2 つ並ぶ。さらに別のタブを押すと、古いほうが外れて押したセンサーが主になる（同時に測れるのは 2 つまで）
- 選んでいるタブを押しても何も起きない。OFF にすると、最後に押したセンサーだけが残る。AI タブを押すと OFF に戻る
- 2 つ選んでいる間は、左のカードに「色・名前・現在値・最小/平均/最大」の行がセンサーごとに並び、タブにはチェック印が付く
- 2 つを同じ周期で順に読み、同じ時刻でそれぞれの記録に残す（記録の保存先は単独のときと同じ。最後に押したセンサーが「主」で、表・グラフの表示範囲・測定室の行はその記録を基準にする）
- グラフは時間軸を共通にして、古いほうを上・主センサーを下に並べる。相手の記録は時刻で主センサーに合わせる（選ぶ前に記録した分も、同じ時間帯なら出る）。グラフの箱が高くなるので、低い画面ではページがスクロールする
- グラフの見出しの右に出る「並べる｜重ねる」で、1 枚に重ねることもできる（ブラウザに覚える）。単位が違う組は左の軸を 1 つ目・右の軸を 2 つ目のセンサーの色で描き、目盛りの本数をそろえて横線を共有する。単位が同じ組（温度と水温など）は 1 本の共通の軸
- 表と CSV は時刻ごとに 1 行、センサーごとに 1 列（CSV の見出しに単位）。削除は 2 つまとめて消す
- 測定室には 2 つを 1 本のストリームで送る（測定室のタイルに 2 本の線と現在値が出る）。組を変えると新しいセッションになる
- 記録間隔は 0.5秒 から。音量の 0.1秒 は音量を単独で測るときだけ

## 測定室（共有）

[s-link-logger](../s-link-logger) の測定室をそのまま移植したもの。API（`https://logdb.s-link.education`、AWS 構成は s-link-logger の `infra/`）も測定室のページ（`room.html`）も s-link-logger と同じものを使う。

- 画面右下の「測定室」ボタンで作成・参加する。ボタンの丸い印で、データを送れているか（緑）・送れていないか（橙）が分かり、公開中はボタンに「（公開中）」と出る
- 「作成する」… 測定室の名前と自分の端末名を入れると 6 桁の測定室 ID ができる。「自身のデータ共有」を外すと、作成した端末は測定室を管理するだけで自分のデータは送らない
- 「参加する」… 測定室 ID と自分の端末名を入れる。6 桁そろうと測定室の名前が出るので、確かめて「参加する」
- 「別タブで測定室を表示」… 端末ごとのタイル（現在値と小さなグラフ）。拡大・重ねて表示・ダウンロードができる
- 作成者は「公開する」で、URL を知っている人にも見せられる（URL のコピーと QR コード）。「終了する」は 2 回押しで確定
- 送るのは「いま選んでいるセンサーの記録」（くらべているときはその組）。5 秒ごとに差分を送り、センサーを切り替えたり記録を削除したりすると、新しいセッションとしてその端末の分をサーバー側で入れ替える（AI タブも同じ。回答文は送らない）
- 端末の登録と測定室はブラウザ（localStorage）に残り、ページを開き直しても続く。最後の送信から 1 週間で自動で消える
- QR コードの生成は `qrcode.js`（qrcode-generator v1.4.4、MIT。s-link-logger の `vendor/` から複製）を、押されたときだけ読み込む

## URL パラメータ

| パラメータ | 内容 |
|---|---|
| `mode=demo` | ボードの代わりに乱数の値を流す（接続ボタンの代わりに「デモ値（乱数）」と「終了」が出る） |
| `api=URL` | 測定室の共有 API の URL（既定 `https://logdb.s-link.education`。開発用） |
| `preview=ipad` | PC で iPad 向けの「Scrub で開く」案内を確かめる |

## 動作環境

- Web MIDI API に対応したブラウザ（Chrome、Edge など）
- iPad は Safari / Chrome に Web MIDI が無いため、Scratch専用ブラウザ [Scrub](https://apps.apple.com/jp/app/scrub/id1569777095) で開いてください。iPad の通常ブラウザで開くと「Scrub で開く」の案内が出ます（`scrub://openUrl?<このページのURL>` で Scrub に渡します）。PC で案内の表示を確かめるには `?preview=ipad` を付けます
- AkaDako / S-LINK センサーボード
- カメラ・マイクを使う項目は `https://` または `localhost` での配信が必要です（`file://` では許可されない場合があります）
