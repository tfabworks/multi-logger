# AkaDako Multi Logger(β)

AkaDako / S-LINK センサーボードの値をブラウザでリアルタイムに表示・記録する、1ファイル構成の教材用Webアプリです。

## 機能

- Web MIDI 経由で AkaDako / S-LINK ボードに接続
- センサー14項目: 温度・照度・距離・湿度・気圧・重力・傾き・動き・音量・水温・酸素・電流・電圧・電力
  - 「動き」はパソコンのカメラ、「音量」はマイクを使うため、ボードなしでも測れます
- 記録していないときも現在値を1秒ごとに更新
- グラフ表示と表表示の切り替え
  - グラフの下のスクロールバー: 灰色の部分の中央を左右にドラッグすると見える時間帯が動き、両端をドラッグすると見える範囲の長さが変わる（10 件〜全部。初期値は直近 120 件）。右端まで動かすと最新の記録を追いかける
  - 記録が止まっているときにグラフの上を左右にドラッグすると、その範囲が灰色になり「この範囲を拡大」で選んだ範囲をグラフいっぱいに出せる（記録は消えない）
- CSV ダウンロード / TSV コピー（Excel・スプレッドシートに貼り付け）
- 「測定室」: 複数の端末の測定データを集めて 1 つのページで見る（下の「測定室」を参照）
- `?mode=demo` を付けて開くと、ボードの代わりに乱数の値を流すデモになる（見た目の確認用。カメラ・マイク・生成AI も使わない）
- 「AI」タブで AI 計測: 記録間隔（5秒/10秒/1分/10分）ごとにカメラの画像とプロンプトを AkaDako 生成AI に送り、答えの数字を表・CSV に記録（回答文も一緒に残ります）
  - 利用には S-LINK ボードの接続と、[AkaDako Cloud Plus のアクセスコード](https://699.jp/cp) の登録が必要です
  - アクセスコードの Cookie は xcratch.699.jp のものなので、同一サイトになる https://log.699.jp/ から開いてください

## 使い方

1. https://log.699.jp/ を開く（手元で動かすときは `index.html` を `https://` か `localhost` 経由で開く）
2. 「ボードに接続」で S-LINK ボードに接続
3. センサーのタブを選び、「記録をはじめる」で記録を開始

外付けの機器が必要なセンサー（水温・酸素・電流・電圧・電力）は、タブを押したときに接続先の案内が出ます。

## 測定室（共有）

[s-link-logger](../s-link-logger) の測定室をそのまま移植したもの。API（`https://logdb.s-link.education`、AWS 構成は s-link-logger の `infra/`）も測定室のページ（`room.html`）も s-link-logger と同じものを使う。

- 画面右下の「測定室」ボタンで作成・参加する。ボタンの丸い印で、データを送れているか（緑）・送れていないか（橙）が分かり、公開中はボタンに「（公開中）」と出る
- 「作成する」… 測定室の名前と自分の端末名を入れると 6 桁の測定室 ID ができる。「自身のデータ共有」を外すと、作成した端末は測定室を管理するだけで自分のデータは送らない
- 「参加する」… 測定室 ID と自分の端末名を入れる。6 桁そろうと測定室の名前が出るので、確かめて「参加する」
- 「別タブで測定室を表示」… 端末ごとのタイル（現在値と小さなグラフ）。拡大・重ねて表示・ダウンロードができる
- 作成者は「公開する」で、URL を知っている人にも見せられる（URL のコピーと QR コード）。「終了する」は 2 回押しで確定
- 送るのは「いま選んでいるセンサーの記録」。5 秒ごとに差分を送り、センサーを切り替えたり記録を削除したりすると、新しいセッションとしてその端末の分をサーバー側で入れ替える（AI タブも同じ。回答文は送らない）
- 端末の登録と測定室はブラウザ（localStorage）に残り、ページを開き直しても続く。最後の送信から 1 週間で自動で消える
- QR コードの生成は `qrcode.js`（qrcode-generator v1.4.4、MIT。s-link-logger の `vendor/` から複製）を、押されたときだけ読み込む

## URL パラメータ

| パラメータ | 内容 |
|---|---|
| `mode=demo` | ボードの代わりに乱数の値を流す（接続ボタンは出ない） |
| `api=URL` | 測定室の共有 API の URL（既定 `https://logdb.s-link.education`。開発用） |
| `preview=ipad` | PC で iPad 向けの「Scrub で開く」案内を確かめる |

## 動作環境

- Web MIDI API に対応したブラウザ（Chrome、Edge など）
- iPad は Safari / Chrome に Web MIDI が無いため、Scratch専用ブラウザ [Scrub](https://apps.apple.com/jp/app/scrub/id1569777095) で開いてください。iPad の通常ブラウザで開くと「Scrub で開く」の案内が出ます（`scrub://openUrl?<このページのURL>` で Scrub に渡します）。PC で案内の表示を確かめるには `?preview=ipad` を付けます
- AkaDako / S-LINK センサーボード
- カメラ・マイクを使う項目は `https://` または `localhost` での配信が必要です（`file://` では許可されない場合があります）
